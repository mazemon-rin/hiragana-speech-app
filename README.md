# おしゃべり五十音表
大きな文字でかんたん操作。言葉を作って音声で伝えよう。
![おしゃべり五十音表](hiragana.png)
ひらがなを選んで言葉を作り、日本語音声で読み上げるWebアプリです。

子どものひらがな学習、高齢者の発声練習、簡単なコミュニケーション支援を目的に作成しました。
## 主な機能

- ひらがな入力
- カタカナ/ひらがな切り替え
- 日本語音声読み上げ
- 読み上げ速度変更
- 1文字削除
- 全削除
- お気に入り登録
- 読み上げ履歴
- カテゴリ別の定型文
- コミュニケーションモード
- スマートフォン対応
- ブラウザだけで利用可能
